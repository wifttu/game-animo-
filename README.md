# 루미 아일랜드 (Lumi Island)

모바일 브라우저에서 바로 플레이할 수 있는 **3D 생존 시뮬레이션 게임**입니다.
낯선 섬에서 자원을 모으고, 도구를 만들고, 집터를 꾸리고, 빛나는 생물 "루미"를 길들여 함께 살아남으세요.

- 엔진: [three.js](https://threejs.org) (저장소에 포함, 빌드 과정 없음)
- 모든 3D 모델·지형·효과음은 코드로 생성합니다 (외부 에셋 없음)
- 진행 상황은 기기에 자동 저장됩니다 (localStorage)

## 실행 방법

정적 파일만으로 동작합니다. 저장소 폴더에서 아무 정적 서버나 띄우면 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

**휴대폰에서 플레이하려면** GitHub Pages를 켜는 것이 가장 간단합니다.
저장소 Settings → Pages → *Deploy from a branch* 에서 이 브랜치와 `/ (root)` 를 선택하면
`https://<사용자명>.github.io/<저장소명>/` 주소로 접속할 수 있습니다. 홈 화면에 추가하면 전체 화면 앱처럼 실행됩니다.

## 조작

| | 모바일 | PC |
|---|---|---|
| 이동 | 화면 왼쪽 드래그(조이스틱) | WASD / 방향키 |
| 달리기 | 조이스틱을 끝까지 밀기 | Shift |
| 시점 | 화면 오른쪽 드래그, 두 손가락으로 줌 | 마우스 드래그, 휠 |
| 행동(줍기·벌목·채광·공격·상호작용) | 행동 버튼 (누르고 있으면 반복) | E 또는 F |
| 점프 | 점프 버튼 | Space |
| 단축 슬롯 | 슬롯 탭 (선택된 음식·설치물은 한 번 더 탭하면 사용) | 1~6 |
| 가방 / 제작 / 목표 / 설정 | 우측 상단 버튼 | I / C / Q / Esc |
| 건축 회전 | 회전 버튼 | R |

## 구현된 시스템

- **월드**: 노이즈 기반 섬 지형(해변·초원·숲·호수·설산), 수심/물거품이 표현되는 물, 낮밤 주기와 하늘·별·구름, 실시간 그림자, 바람에 흔들리는 풀
- **생존 스탯**: 체력·허기·갈증·체온·기력. 밤과 고지대는 춥고, 모닥불·횃불·가죽 외투로 체온을 지킵니다
- **채집**: 나무·바위·철광석·열매 덤불·나뭇가지·돌멩이·부싯돌·억새풀·버섯·약초 (시간이 지나면 재생)
- **인벤토리**: 24칸 가방 + 6칸 단축 슬롯, 도구 내구도, 방어구 착용
- **제작**: 맨손 / 작업대 / 모닥불(요리) / 화로(제련) 4단계, 24종 제작법
- **건축**: 모닥불·작업대·화로·텐트·보관 상자·텃밭·울타리·벽·바닥 설치 및 철거
- **농사**: 텃밭에 씨앗을 심어 당근 수확
- **동물**: 토끼·사슴(도망), 멧돼지(공격받으면 반격), 늑대(밤에 출몰, 모닥불을 무서워함)
- **길들이기**: 루미에게 숲 열매를 3번 주면 동료가 되어 밤길을 밝히고 적과 싸웁니다
- **성장**: 경험치·레벨, 20단계 목표(튜토리얼 겸 진행 가이드)
- **그래픽**: 빛 번짐(블룸)·색 보정 후처리, 절차적 구름과 태양 후광, 지형 질감, 바람에 흔들리는 나무, 반딧불이·불티 (품질 3단계)
- **사운드**: 낮/밤에 따라 바뀌는 생성형 배경음악, 새소리·귀뚜라미 환경음, 합성 효과음
- **조작 설정**: 조이스틱·행동·점프 버튼·단축 슬롯 위치를 드래그로 변경, 조이스틱 자유/고정 방식, 버튼 크기
- **기타**: 미니맵, 텐트 취침(밤 건너뛰기·부활 지점), 자동 저장

## 코드 구조

```
index.html        HUD 마크업, 진입점
css/style.css     모바일 우선 UI 스타일
js/main.js        부트스트랩 · 메인 루프
js/world.js       지형 · 물 · 하늘 · 낮밤 조명
js/nodes.js       자원 노드 (InstancedMesh)
js/animals.js     동물 AI · 스폰 · 펫
js/structs.js     설치물 · 건축 모드 · 충돌
js/player.js      캐릭터 · 이동 · 카메라
js/actions.js     상호작용 · 제작 · 전투 · 생존 스탯
js/items.js       아이템 · 제작법 · 인벤토리
js/quests.js      목표 시스템
js/ui.js          HUD · 패널 · 미니맵
js/geo.js         절차적 로우폴리 모델
js/post.js        후처리(블룸·색 보정)
js/layout.js      조작 버튼 배치 편집
js/fx.js, audio.js, input.js, save.js, util.js
vendor/           three.js 및 후처리 모듈
```

주소 끝에 `?debug` 를 붙이면 콘솔에서 `__G`, `__dbg` 로 게임 상태를 다룰 수 있습니다.
